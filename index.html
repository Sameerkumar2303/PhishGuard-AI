📖 Understanding Supervised Learning in Cybersecurity

ML Fundamentals

1. What is Supervised Learning?

Supervised Learning is a branch of Machine Learning where an algorithm learns a mapping function from input features $(X)$ to a target label $(Y)$ based on pre-labeled training examples. In Phishing Detection, each sample is represented by an extracted vector of 15 numerical features, with binary target labels:

$Y \in \{0, 1\}$   |   $0 = \text{Legitimate Website}$,    $1 = \text{Phishing Website}$

2. The End-to-End Supervised ML Pipeline

01

Data Collection & Labeling

Gathering known malicious phishing feeds (PhishTank, OpenPhish) and verified benign websites (Alexa Top, Tranco).

02

Feature Extraction

Parsing raw URL strings into 15 numeric and binary heuristic features (length, IP hostname, entropy, keywords).

03

Train / Test Splitting

Partitioning data (e.g. 75% Training / 25% Testing) to objectively measure generalization on unseen URLs.

04

Model Optimization

Training models using Gradient Descent, Bayesian probabilities, and Information Gain tree partitioning.

05

Validation & Metrics

Evaluating Accuracy, Precision, Recall, F1-Score, Confusion Matrix, and ROC/AUC curves.

06

Real-Time Inference

Extracting features live from user-entered URLs and producing an instant calibrated risk score.

3. Implemented Supervised Algorithms & Mathematical Formulas

A. Logistic Regression

A linear model transformed via the sigmoid activation function to output a calibrated probability between 0 and 1.

Sigmoid: $\sigma(z) = \frac{1}{1 + e^{-z}}$, where $z = \mathbf{w}^T\mathbf{x} + b$
Loss: $J(\mathbf{w}) = -\frac{1}{m}\sum [y\log(\hat{y}) + (1-y)\log(1-\hat{y})]$

B. Gaussian Naive Bayes

Applies Bayes' Theorem assuming conditional feature independence given the class.

Posterior: $P(Y|X) = \frac{P(Y) \prod P(X_i|Y)}{P(X)}$
Gaussian Likelihood: $P(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

C. Decision Tree

Constructs hierarchical if-else decision rules by selecting feature thresholds that minimize impurity.

Gini Impurity: $Gini(p) = 1 - \sum_{k=0}^1 p_k^2$
Information Gain: $\Delta Gini = Gini_{parent} - \sum \frac{|S_v|}{|S|} Gini(S_v)$

D. Random Forest Ensemble

Ensemble of $N$ decision trees trained on bootstrap samples and random feature subspaces; predictions are aggregated via majority voting.

$\hat{Y} = \text{mode}\left(\{ Tree_1(X), Tree_2(X), \dots, Tree_N(X) \}\right)$

4. Evaluation Metrics for Phishing Detection

In cyber defense, evaluating models beyond simple accuracy is vital because False Negatives (missing a phishing website) can cause catastrophic credential theft, while False Positives (blocking legitimate banks) frustrate users:

Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$   |   Precision: $\frac{TP}{TP + FP}$   |   Recall (Sensitivity): $\frac{TP}{TP + FN}$   |   F1-Score: $2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$
